## 技术说明

本仓库为 Next.js 静态导出项目，部署在 GitHub Pages 二级路径 `/okyi/`。

### 本地开发

```bash
npm install
npm run dev
```

### 构建

```bash
npm run build
```

静态产物在 `out` 目录，由 GitHub Actions 发布至 Pages。

### 多语言

- 简体：根路径 `/okyi/`  
- 繁体：`/okyi/zh-hant/`，页面数据在构建期由 OpenCC 生成繁体副本
